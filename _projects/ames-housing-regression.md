This project used the Ames housing data to study how sale price relates to above-ground living area across BrkSide, Edwards, and NAmes and to build competing linear regression models for predicting sale prices throughout Ames, Iowa.

The work included log transformations, interaction modeling, regression diagnostics, influential-observation analysis, feature selection, adjusted R-squared, CV PRESS, and Kaggle validation. The selected nine-predictor log multiple regression model achieved an adjusted R-squared of 0.8756 and a public Kaggle score of 0.16030.

The Shiny application displays SalePrice versus GrLivArea and allows users to view BrkSide, Edwards, and NAmes separately, as required by the project rubric.
