Featured Project

NYC Yellow Taxi Tipping Project

This project used 2025 NYC Yellow Taxi trip data to predict recorded tip amount and explain which trip characteristics were most useful for the model. The final model was a multiple linear regression model built in R and delivered through a Shiny dashboard with EDA, model results, and a RAG question-answer component.

1.30 Test RMSE
0.92 Test MAE
RAG Project Q&A

Tools: R, Shiny, linear regression, RAG, project notes as a knowledge base, and a deployed dashboard for interactive exploration.

Featured Project

Employee Attrition Case Study

This case study analyzed employee attrition patterns for a workforce retention scenario where replacement costs can materially affect operating performance. EDA compared attrition rates across workforce categories and showed the strongest separation for job role, job involvement, stock option level, work-life balance, overtime, and job level.

72.4% Accuracy
78.0% Sensitivity
71.4% Specificity

Selected model: tuned Naive Bayes with a 0.50 threshold after comparing performance against tuned KNN. The final model used overtime, job level, stock option level, work-life balance, and job involvement because they were interpretable, available for scoring, and supported by the EDA spread analysis.
