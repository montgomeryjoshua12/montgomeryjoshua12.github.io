Featured Project

NYC Yellow Taxi Tipping Project

This project used 2025 NYC Yellow Taxi trip data to predict recorded tip amount and explain which trip characteristics were most useful for the model. The final model was a multiple linear regression model built in R and delivered through a Shiny dashboard with EDA, model results, and a RAG question-answer component.

1.30 Test RMSE
0.92 Test MAE
RAG Project Q&A

Tools: R, Shiny, linear regression, RAG, project notes as a knowledge base, and a deployed dashboard for interactive exploration.

Featured Project

Employee Attrition Case Study

This case study analyzed employee attrition patterns for a workforce retention scenario where replacement costs can materially affect operating performance. The workflow centered on Naive Bayes versus KNN comparison, manual oversampling for class imbalance, and threshold tuning to balance sensitivity and specificity against a 60% business performance benchmark.

72.4% Accuracy
78.0% Sensitivity
71.4% Specificity

Selected model: tuned Naive Bayes with a 0.50 threshold after comparing performance against tuned KNN. Threshold tuning matters because HR leaders need to catch employees at risk of leaving without over-flagging employees who would have stayed.
